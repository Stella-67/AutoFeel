STEP 1: Get API Key (2 minutes)
  Option A: OpenAI (GPT-4)
    → Go to https://platform.openai.com/api-keys
    → Create API key
    → Copy and save securely

  Option B: Anthropic (Claude)
    → Go to https://console.anthropic.com/
    → Create API key
    → Copy and save securely

STEP 2: Load Extension (2 minutes)
  1. Open: chrome://extensions/
  2. Enable: Developer Mode (top right)
  3. Click: Load unpacked
  4. Select: /home/sl3348/project/Agentic folder
  5. Done! Extension appears in list

STEP 3: Configure (1 minute)
  1. Click extension icon
  2. Go to: Settings tab
  3. Paste: API key
  4. Choose: LLM provider (OpenAI/Anthropic)
  5. Click: Save LLM Settings

STEP 4: Build Profile (10 minutes)
  1. Click: My Profile tab
  2. Fill in: Personal info, education, experience, skills
  3. Add: Stories/examples
  4. Save: Each section

STEP 5: Test (5 minutes)
  1. Go to: Any application form
  2. Click: Extension icon
  3. Click: Detect Form Fields
  4. Click: Generate Answer
  5. Click: Fill Field
