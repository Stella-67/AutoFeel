图标占位说明
=============

这个目录需要包含以下尺寸的图标：
- icon-16.png  (16x16 像素)
- icon-48.png  (48x48 像素)
- icon-128.png (128x128 像素)

你可以使用任何图像编辑工具创建这些图标，或者临时使用在线工具：
- https://www.favicon-generator.org/
- https://www.canva.com/
- https://www.figma.com/

建议的图标主题：
- 📋 表单/剪贴板
- 🤖 机器人/AI
- ⚡ 闪电/自动化
- 🚀 火箭

在正式发布前，请替换为专业设计的图标。
